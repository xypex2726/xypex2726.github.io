Privacy Policy

This application is a personal tool used only by its owner to upload the owner's own files to the owner's own Google Drive.

Data we access

The app uses the Google Drive scope "drive.file", which gives access only to files and folders created by the app itself. It cannot see or modify any other files in the account.

How data is used

Data is used only to upload and manage files created by the app. It is not sold, shared, or transferred to any third party. No data is collected on any server; the access token is stored only on the owner's own computer.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
